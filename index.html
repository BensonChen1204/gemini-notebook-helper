Gemini Notebook Helper

A personal helper application for use with Gemini Notebook (NotebookLM).

What this application is

Gemini Notebook Helper is a small personal-use application developed and used by a single individual — the developer himself, Benson Chen. It is not a public product, it is not offered to other users, and it has no sign-up or account system of its own.

The application works through Google's official Gemini Notebook API. Acting only on the developer's own instructions, it helps him organise material in his own personal Google account (neihu0122@gmail.com) by creating notebooks and adding sources to them.

What it does

  • Creates new notebooks in the developer's personal Gemini Notebook account.
  • Adds sources to those notebooks: web pages, YouTube videos, plain text, and Markdown.
  • Lists notebooks and sources so their processing status can be checked.

Data access

The application requests a single OAuth scope, https://www.googleapis.com/auth/notebook, which allows it to view and manage notebooks and their sources in the signed-in account. It accesses no other Google data. OAuth credentials are stored only on the developer's own computer, in a permission-locked local store. The application does not operate a server that collects data, does not send data to third parties, does not sell data, and includes no advertising or analytics tracking.

Access can be revoked at any time from the Google Account permissions page. For details on how information is handled, please read the Privacy Policy.
